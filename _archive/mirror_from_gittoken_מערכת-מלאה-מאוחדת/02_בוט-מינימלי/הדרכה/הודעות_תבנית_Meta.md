# הודעות תבנית (Template Messages) ב-Meta / WhatsApp Business API

כשעובדים עם WhatsApp Business API דרך WATI, Green API או כלים דומים, יש מקרים שבהם אי אפשר לשלוח הודעה חופשית מחוץ ל-24 השעות האחרונות.

## מתי זה רלוונטי?
- שליחה מחוץ לחלון 24 שעות מאז תגובת הלקוח
- הודעה יזומה
- במקרים מסוימים ב-WATI

## מה לעשות?
1. בדוק Templates ב-WATI
2. השתמש בתבנית פשוטה בעברית מאושרת ע"י Meta
3. עדיף לעבוד בתוך חלון 24 שעות

## חשוב
אם הבוט מגיב בלבד לפנייה נכנסת - לרוב פחות צורך בתבניות. אם שולחים יזום - בדרך כלל נדרש תבנית מאושרת.
