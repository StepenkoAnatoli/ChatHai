# חיפוש לידים נכון | אינסטלטורים בעיר אחת בלבד

אל תחפש בארץ כולה. **בחר עיר אחת בלבד** והפוך אותה לאזור שלך. זה הרבה יותר אפקטיבי מלהתפזר. 


## בחירת העיר

בחר עיר שבה יש המון בעלי עסקים קטנים, ולא רק רשתות גדולות.

| קריטריון | המלצה |
| :-- | :-- |
| **גודל אידיאלי** | עיר בינונית (רמת גן, פתח תקווה, נתניה, חולון וכו') |
| **הימנע מ** | תל אביב-יפו (תחרות גבוהה מאוד, לפעמים יותר שקועים בעבודה) |
| **עדיף** | ערים פרבריות עם המון שכונות חדשות וותיקות (יש המון אינסטלטורים עצמאיים שם) |


## איפה לחפש

## קריטריונים לסינון (חובה)

אל תוסיף מישהו לרשימה אם הוא לא עומד ברוב הקריטריונים. עדיף 5 איכותיים מ-20 לא מתאימים.

| קריטריון | דרישה | הסבר |
| :-- | :-- | :-- |
| **סוג העסק** | **בעל עסק עצמאי / 1-3 אנשים** | הכי נגיש, הכי מהיר לקבל תשובה, הכי קל לשכנע. |
| **שם העסק** | אישי או קטן | אם זה שם משפחה + אינסטלטור, זה בדרך כלל עצמאית. |
| **אתר אינטרנט** | **ישן או פשוט** | אתר בלי מערכת הזמנות מורכבת = הרבה יותר פתוח לפתרון פשוט כזה. |
| **מספר טלפון** | **נייד או קו ישיר של העסק** | עדיף מספר שמגיע ישר לבעל העסק. אם יש רק מוקד מרכזי עם תפריט ארוך - דלג. |
| **מרחק** | **בעיר שבחרת בלבד** | שמור על זה ממוקד. קל יותר להגיע למצב של "אני מכיר את האזור". |


## איך לחפש בגוגל מפות

1. **חיפוש** - כתוב בעברית: `אינסטלטור [שם העיר]`
2. **סרוק את התוצאות** - עבור על התוצאות הראשונות והסתכל על כל אחת
3. **בדוק את הפרופיל** - לחץ על העסק, בדוק את האתר, השעות, התיאור
4. **סנן** - אם נראה כמו עסק גדול עם המון עובדים/סניפים -> דלג
5. **אסוף** - הוסף רק את אלו שנראים כמו עסק משפחתי/עצמאי לרשימה


## מילוי הרשימה

השתמש בקובץ `מעקב/רשימת_לידים.csv`. מלא את העמודות הבאות בצורה מדויקת.

| עמודה | איך למלא |
| :-- | :-- |
| **שם_העסק** | השם המדויק כפי שמופיע בגוגל מפות |
| **טלפון** | מספר הטלפון ישירות מהפרופיל |
| **בעל_עסק** | אם הצלחת לזהות שם של בעל העסק (לא חובה, אבל עוזר מאוד) |
| **אתר** | אם קיים |
| **כתובת/אזור** | מספיק שם השכונה או העיר |
| **סטטוס** | תמיד מתחיל ב-`טרם_הותקשר` |
| **הערות** | הסבר קצר למה בחרת אותו (למשל: "אתר ישן", "עסק משפחתי", "נראה עצמאי") |


## מטרה

עדיף לקחת 5 אינסטלטורים שבאמת מתאימים לקריטריונים, ולהתקשר אליהם בצורה יסודית, מאשר לקחת 20 שלא מתאימים ולהתייאש.
