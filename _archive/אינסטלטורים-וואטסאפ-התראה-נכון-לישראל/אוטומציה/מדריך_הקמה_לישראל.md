# מדריך הקמה לישראל | שיחה שלא נענתה -> הודעת וואטסאפ לאינסטלטור

המטרה היא רק זרימה אחת ופשוטה: **שיחה שלא נענתה -> הודעת וואטסאפ נשלחת ללקוח תוך פחות מדקה -> התראה מיידית לאינסטלטור שיחזור אליו.**

אל תוסיף שום פיצ'ר נוסף. פשוט לגרום לזה לעבוד בצורה אמינה.


## לפני שמתחילים

יש לך צורך ב:

- [ ] חשבון ב-**WATI** או **Green API** עם WhatsApp Business API מחובר
- [ ] מספר טלפון וירטואלי או פשוט את האפשרות לבצע **העברת שיחה (Call Forwarding)** מהמכשיר של האינסטלטור
- [ ] מספר טלפון של האינסטלטור (כדי לשלוח לו התראה)
- [ ] הודעת וואטסאפ מוכנה ללקוח


## שלב 1: העברת שיחה (Call Forwarding) - הכי חשוב

זה החלק שיציל אותך מהרבה התנגדויות. **אל תבקש ממנו להחליף את המספר הראשי שלו**. פשוט להעביר אליו את השיחות שלא נענות.

איך עושים את זה?

1. **במכשיר הנייד שלו** - ברוב הטלפונים: הגדרות > שיחות > העברת שיחות > כשלא עונים -> העבר למספר הוירטואלי שקיבלת מהכלי שבחרת.
2. **במכשיר קווי** - תלוי בספק, אבל בדרך כלל אפשר לעשות את זה דרך הספק או בטלפון עצמו.
3. **בדיקה** - תבקש ממנו להתקשר מהטלפון שלך, לא לענות וראה שהשיחה מועברת למספר הוירטואלי שלך.

**טיפ:** הרבה אינסטלטורים יודעים לעשות את זה לבד. אם קשה לו, פשוט תסביר לו צעד אחר צעד בטלפון.


## שלב 2: הקמת האוטומציה

### אופציה A: WATI (מומלץ למתחילים)

1. **היכנס ל-WATI** -> Automations -> Create New Automation
2. **Trigger:** חפש `Missed Call` או השתמש ב-Webhook בהתאם לגרסה הנוכחית שלך. אם אין טריגר ישיר, תשתמש ב-Webhook.
3. **שלח הודעת וואטסאפ ללקוח** 
   - הוסף פעולה `Send Template Message` או `Send Freeform Message`
   - שלח למספר שמתקשר
4. **שלח התראה לאינסטלטור**
   - הוסף פעולה נוספת
   - שלח למספר האינסטלטור: *"שיחה שלא נענתה מ-{{customer_number}}. חזור אליו מהר."*
5. **שמור והפעל**

### אופציה B: Green API + n8n (מומלץ ליציבות)

1. **היכנס ל-n8n** -> צור Workflow חדש בשם `אינסטלטור - התראת שיחה שלא נענתה`
2. **Webhook** - צור Webhook שמקבל מידע על שיחה שלא נענתה
3. **Green API - Send Message** - שלח את הודעת הוואטסאפ ללקוח שהתקשר
4. **Green API - Send Message** - שלח התראה לאינסטלטור עם מספר הטלפון של הלקוח
5. **שמור והפעל**


## שלב 3: כתיבת ההודעות הנכונות

תשתמש בהודעות קצרות וטבעיות. פחות מילים = יותר אפקטיבי.

### הודעת וואטסאפ ללקוח

העתק בדיוק את זה:

```text
היי, קיבלנו את השיחה שלך. נחזור אליך ממש בקרוב. תודה!
```


### התראה לאינסטלטור

העתק בדיוק את זה:

```text
שיחה שלא נענתה מ: {{מספר_המתקשר}}
חזור אליו עכשיו.
```


## שלב 4: בדיקה חובה לפני הצגה ללקוח

חייב לעבור את הרשימה הזו לפני שאתה מציג את הדמו לאינסטלטור כלשהו.

- [ ] **העברה פועלת** - ביצעת שיחה מהטלפון שלך, לא ענית והטלפון הועבר
- [ ] **הודעה ללקוח מגיעה** - הודעת וואטסאפ נכנסת לטלפון שלך תוך פחות מ-60 שניות
- [ ] **התראה לאינסטלטור מגיעה** - הודעה נכנסת למספר שבחרת עם מספר המתקשר
- [ ] **ניסוי חוזר** - עשית את זה **פעם שנייה ושלישית** ומוודא שזה עובד כל פעם באותו אופן
- [ ] **יציב** - אין שגיאות בממשק של WATI/Green API
- [ ] **מהיר** - התגובה מהירה, לא לוקח 2-3 דקות


## טיפים חשובים לאמינות

- **פחות אלמנטים = פחות בעיות**. אל תוסיף טיימרים, אל תוסיף רשימות, אל תוסיף פיצ'רים. רק 2 פעולות.
- **תבדוק עם מספר אמיתי**. בדיקה מהקונסול לא מספיקה. חייב לבדוק עם שיחת אמת.
- **העברת שיחה עדיפה על החלפת מספר**. זה ההבדל בין "אולי" ל"כן".
- **תעדף אמינות על יופי**. אם המערכת עובדת 9/10 פעמים, היא לא מספיק טובה. **צריך 10/10** בשביל להציג לראשונה לבעל מקצוע ישראלי אמיתי. 


**המטרה היא מערכת פשוטה, יציבה ובטוחה להציג להדמו האמיתי שלך.**
