# חיפוש לידים נכון | אינסטלטורים או חשמלאים

**בחר קטגוריה אחת בלבד.** חפש בעיר אחת בלבד.

## בחירת העיר

בחר עיר בינונית (רמת גן, פתח תקווה, נתניה, חולון וכו'). הימנע מתל אביב-יפו אם אפשר.

## איפה לחפש

- [Google Maps](https://maps.google.com/) - **הכי חשוב**

## חיפושים

חפש **אחד** מהבאים:

1. `אינסטלטור [עיר]`
2. `חשמלאי [עיר]`

**השווה:** איזו קטגוריה נותנת יותר תוצאות שנראות כמו בעלי עסק של 1-3 אנשים? בחר **רק אותה**.

## קריטריונים לסינון

| קריטריון | דרישה | הסבר |
| :-- | :-- | :-- |
| **גודל** | 1-3 אנשים | הכי נגיש וקל לקבל החלטה |
| **עצמאי** | שם משפחה או שם פרטי + מקצוע | פחות סיכוי שזה רשת/מרכזייה |
| **אתר** | ישן/פשוט או אין אתר מורכב | יותר פתוח לפתרון פשוט |
| **מספר** | ישיר לבעל העסק | עדיף על מוקד |
| **ללא מרכזייה גלויה** | כן | מרכזיות לרוב פחות מתעניינות |
