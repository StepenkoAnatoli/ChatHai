# מדריך הקמה לישראל | שיחה שלא נענתה -> הודעת וואטסאפ

המטרה: **זרימה פשוטה, יציבה ואמינה**. רק: שיחה שלא נענתה -> הודעת וואטסאפ ללקוח -> התראה לבעל העסק.

## לפני שמתחילים

- [ ] חשבון ב-WATI או Green API עם WhatsApp Business API מחובר
- [ ] מספר הוירטואלי / אפשרות ל-Call Forwarding
- [ ] מספר הטלפון של האינסטלטור/חשמלאי לקבלת התראה


## שלב 1: העברת שיחה (Call Forwarding)

**חשוב:** אל תבקש להחליף את המספר הראשי. רק להעביר שיחות שלא נענות.

1. במכשיר הנייד של האינסטלטור/חשמלאי: **הגדרות > שיחות > העברת שיחות > כשלא עונים** -> העבר למספר הוירטואלי שלך
2. בדוק עם שיחה מהטלפון שלך (לא לענות) שהשיחה מועברת

## שלב 2: הגדרת ה-Trigger והפעולות בצורה מדויקת

### א) WATI

1. **Automations > Create Automation**
2. **Trigger:** חפש `Missed Call` אם קיים. אם אין - השתמש ב-**Webhook** וקבל את פרטי השיחה מהחיבור שלך.
3. **Action 1 - שלח הודעת וואטסאפ ללקוח**
   - פעולה: `Send WhatsApp Message` 
   - אל הלקוח שהתקשר
   - שימוש בהודעה קצורה וטבעית
4. **Action 2 - שלח התראה לבעל העסק**
   - פעולה: `Send WhatsApp Message`
   - אל מספר האינסטלטור/חשמלאי
   - הודעה עם מספר המתקשר

### ב) Green API + n8n

1. **Webhook Trigger** - מקבל נתוני שיחה שלא נענתה
2. **Green API > Send Message** - שלח הודעה ללקוח שהתקשר
3. **Green API > Send Message** - שלח התראה לבעל העסק עם מספר המתקשר


## שלב 3: התייחסות ל-Template Messages (חשוב לישראל)

ב-WhatsApp Business API, **אם השיחה מתחילה מהצד שלך ולא מהלקוח**, לעיתים נדרש להשתמש ב-**Message Template** שאושר ע"י Meta.

**כללים:**

- **אם הלקוח כבר כתב לך** -> אפשר להשתמש בהודעה חופשית
- **אם אתה מתחיל את השיחה לראשונה בגלל שיחה שלא נענתה** -> לפעמים צריך **Template Message** מאושר
- **ב-WATI** בדרך כלל יש תבניות מוכנות או מאפשרים ליצור ולבקש אישור
- **ב-Green API** צריך לוודא שה-template אושר לפני השימוש

**המלצה:** צור template פשוט ואושר: "קיבלנו את הפנייה שלך, נחזור אליך בהקדם." עם משתנה למספר/מידע מינימלי. אל תכתוב טקסט ארוך. פשוט וקצר יאושר מהר יותר.


## שלב 4: הודעות לשימוש

### הודעה ללקוח
```text
היי, קיבלנו את השיחה שלך. נחזור אליך ממש בקרוב. תודה!
```

### התראה לבעל העסק
```text
שיחה שלא נענתה מ: {{מספר_המתקשר}}
חזור אליו עכשיו.
```


## שלב 5: בדיקה חובה

- [ ] העברה עובדת (שיחה שלא נענתה מועברת)
- [ ] הודעה ללקוח מגיעה תוך פחות מ-60 שניות
- [ ] התראה לבעל העסק מגיעה עם המספר הנכון
- [ ] נבדק **3 פעמים ברצף** עם מספר אמיתי
- [ ] בדקתי Template אם נדרש (ולא רק freeform)
- [ ] המערכת יציבה ללא שגיאות


## טיפים

- **פחות = אמין יותר.** רק 2 פעולות. זה מספיק.
- **בדוק אמיתי.** לא רק תצוגה מקדימה.
- **Call Forwarding עדיף.** פחות התנגדות, יותר סיכוי להסכמה.
