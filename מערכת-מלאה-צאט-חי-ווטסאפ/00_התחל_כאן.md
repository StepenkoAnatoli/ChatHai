# מערכת מלאה: צ׳אט חי + וואטסאפ

הצ׳אט החי הוא הפרויקט הראשי (הקוד). מערכת הוואטסאפ היא השכבה העסקית, המשפטית ותהליך המכירה, ובעתיד הערוץ השני.

## מבנה
- `00_השוואה.md` - השוואה בין שני החלקים, פערים ומה מתאים לאן
- `01_צאט-חי\` - הקוד. להמשיך לפתח מ-`standard\` (ראה `01_צאט-חי\README.md`). מיון חירום והתראת וואטסאפ קיימים רק ב-`standard\`; `zero\` עוד לא עודכן
- `02_מערכת-וואטסאפ\` - מסמכים: התראה לשיחה שלא נענתה, בוט, אישורים, הגנה משפטית, מכירה ובדיקות

## מקור
זה עותק. המקורות נשארו במקומם ומנוהלים בגיט:
- `livechat\livechat\`
- `אינסטלטורים-חשמלאים-וואטסאפ-מערכת-מלאה-מאוחדת\`

עד שיוחלט על מקור אחד, שינוי בעותק אינו משתקף במקור, ולהפך.

## הרצה מהירה (צ׳אט חי)
```
cd 01_צאט-חי\standard
npm run setup
npm run build
npm test
npm start
```

## צעדים הבאים
1. להחיל את מיון החירום וההתראה ב-`zero\` או להסיר את `zero\`
2. להתאים את ההסכם, ניסיון 14 הימים ותסריטי המכירה מ-`02` לצ׳אט החי
3. webhook לשיחה שלא נענתה בשרת הצ׳אט החי (ראה `00_השוואה.md`)
