# איך למנוע הונאה או תביעה

## מניעת בעיות
| אזהרה | פתרון |
| :-- | :-- |
| **לבקש פרטי כרטיס אשראי** | לעולם לא. רק הסכמה ל-₪699/חודש, אין גבייה אוטומטית בשלב זה |
| **לבקש סיסמאות** | לעולם לא. רק העברת שיחה (Call Forwarding) |
| **התחייבות לכל החיים** | ציין "ניתן לבטל בכל עת" |
| **חיוב לפני אישור** | רק אחרי אישור בוואטסאפ + שהיו תוצאות |
| **להשאיר פעיל אחרי ביטול** | כבה מיד, בדוק עם שיחה |
| **להכניס למערכות** | אל תיכנס ל-CRM, גוגל, תוכנות של הלקוח בכלל |

## אם מישהו טוען "לא אישרתי"
התשובה שלך היא פשוטה:
> *"הראיתי לך את המספרים לאחר 14 יום, הצעתי להמשיך ב-₪699/חודש ורק לאחר שאמרת 'כן' בטלפון שלחתי הודעת אישור בוואטסאפ וענית 'כן'. יש לי צילום מסך של זה."*

**לכן חשוב שתמיד תשמור צילום מסך.**

## טיפים מעשיים
- **פחות מידע אישי** - אל תבקש תעודת זהות
- **פשוט** - השירות הכי פשוט = הכי פחות מקום לטעויות
- **תיעוד תמיד** - תאריך + שעה + מה קרה
- **הורדה מיידית בביטול** - זה הכי חשוב כדי לשמור אמון ולא ליצור בעיות
- **רק אינסטלטורים/חשמלאים קטנים** - בעלי עסק של 1-3 אנשים לרוב הוגנים ופשוטים מאוד בישראל
