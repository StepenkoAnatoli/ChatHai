# רשימת תיעוד חובה

שמור את כל זה ב-CSV או בתיקייה פשוטה בטלפון/מחשב.

## לפני הפעלה
- [ ] תאריך שיחה ראשונה
- [ ] שם העסק + טלפון
- [ ] סוג עסק (אינסטלטור / חשמלאי)
- [ ] הסכמתם לניסוי 14 יום
- [ ] תאריך הפעלה

## במהלך הניסוי
- [ ] תאריך בדיקות
- [ ] מספר שיחות שלא נענו (בין אם אפשר לעקוב)
- [ ] הודעות שנשלחו
- [ ] התראות נשלחו
- [ ] חזרות (אם ידוע)

## אחרי 14 יום
- [ ] תאריך השיחה להצעה
- [ ] הצגתי מספרים? (כן/לא)
- [ ] היו חזרות? (כן/לא)
- [ ] תשובה מילולית (כן/צריך לחשוב/לא)
- [ ] שלחתי הודעת אישור בוואטסאפ? (כן/לא)
- [ ] תשובה בוואטסאפ ("כן") + צילום מסך נשמר? (כן/לא)
- [ ] סטטוס: מועמד / הושבת / ממשיך

## אם ממשיך
- [ ] תאריך התחלת תשלום ₪699
- [ ] סטטוס: ממשיך

## אם מפסיק
- [ ] תאריך בקשת ביטול
- [ ] כיביתי אוטומציה (כן)
- [ ] הסברתי להחזיר העברה (כן)
- [ ] ווידאתי שהוסר (כן)
- [ ] סטטוס: הופסק


**חובה:** צילום מסך של הודעת האישור + התשובה "כן". זה החלק הכי חשוב.
