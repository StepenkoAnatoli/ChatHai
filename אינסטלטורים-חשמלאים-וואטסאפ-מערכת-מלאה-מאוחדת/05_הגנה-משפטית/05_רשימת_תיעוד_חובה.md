## במהלך הניסוי
- [ ] תאריך בדיקות

- [ ] התראות נשלחו
- [ ] חזרות (אם ידוע)

## אחרי 14 יום
- [ ] תאריך השיחה להצעה
- [ ] הצגתי מספרים? (כן/לא)
- [ ] היו חזרות? (כן/לא)
- [ ] תשובה מילולית (כן/צריך לחשוב/לא)
- [ ] שלחתי הודעת אישור בוואטסאפ? (כן/לא)
- [ ] תשובה בוואטסאפ ("כן") + צילום מסך נשמר? (כן/לא)
- [ ] סטטוס: מועמד / ממשיך / הופסק
