# איך לבנות את הבוט ב-WATI

המטרה: לבנות את הגרסה המינימלית במהירות וללא פיצ'רים מיותרים.

## שלב 1: להכנס ל-WATI
1. היכנס ל-[wati.io](https://www.wati.io/)
2. פתח את העסק שלך -> **Chatbots** -> **Create Chatbot**
3. בחר **Start from scratch**

## שלב 2: לבנות את הזרימה

העתק את השלבים לפי הסדר הבא.

### שלב א: ברכה
- **Type:** Message
- **Text:** `היי! איך אפשר לעזור?\n\nבחר אחת מהאפשרויות:`
- **Buttons:** `חירום / דחוף` | `פנייה רגילה`

חבר את הכפתורים לנתיבים המתאימים.

### שלב ב: מיון חירום
כשנבחר `חירום / דחוף` ->
- **Type:** Message + Buttons
- **Text:** `מה הבעיה בדיוק?\nבחר או תאר בקצרה:`
- **Buttons:** `נזילה / דליפה` | `פיצוץ צינור` | `אין מים` | `בעיה חשמלית דחופה` | `אין חשמל` | `אחר - דחוף`

לכל כפתור מחבר ל-**Save Answer** ששומר את הבחירה בשדה `emergency_type`.
**אל** לחבר ישירות ל-Human Handoff - בלעדי סוג התקלה ההתראה תגיע חסרה.

### שלב ג: שם + כתובת בחירום
1. **Question** - `כדי להעביר אותך מהר - איך קוראים לך?` (Text) -> `emergency_name`
2. **Question** - `מה הכתובת המלאה (עיר, רחוב, מספר בית)?` (Text) -> `emergency_address`
3. **Human Handoff** (Assign to team/owner)
   - **Message to customer:** `קיבלתי את הפרטים. מעביר אותך מיד לבעל העסק.\n\nאם אפשר, שלח גם תמונה של הבעיה כאן.`
   - **Message to owner:** `חירום! פנייה דחופה מ-{{emergency_name}} | טלפון: {{contact.phone}} | כתובת: {{emergency_address}} | בעיה: {{emergency_type}}`

### שלב ד: פנייה רגילה
כשנבחר `פנייה רגילה` ->
1. **Question** - `איך קוראים לך?` (Text)
2. **Question** - `מה הכתובת? (עיר + רחוב + מספר בית)` (Text)
3. **Question** - `תאר בקצרה את הבעיה` (Text)
4. **Question** - `אם יש תמונה - שלח אותה. אם אין, לחץ "אין תמונה".` (Image/Media + כפתור דילוג)
5. **Message + Button** - סיכום + כפתור `העבר לנציג`
6. **Human Handoff** - עם סיכום כל הפרטים לבעל העסק

## שלב 3: הגדרות חשובות

| הגדרה | מצב | הערות |
| :-- | :-- | :-- |
| **Human Handoff** | פעיל | חובה. חייב לאפשר העברה לאדם |
| **Business Hours** | אופציונלי | אפשר להשאיר כבוי או להגדיר. לא הכרחי |
| **Fallback** | פעיל | אם לקוח כותב משהו שלא מובן -> `כדי שנעביר אותך לנציג, לחץ על "העבר לנציג"` + כפתור |
| **Keywords לחירום** | להוסיף | `נזילה`, `דליפה`, `פיצוץ`, `אין מים`, `חשמל`, `אין חשמל` |

## שלב 4: שמירה והפעלה
1. **Test Chatbot** - בדוק את כל הנתיבים
2. **Publish** - פרסם את הבוט
3. **Enable** - הפעל אותו למספר הוואטסאפ של העסק

## טיפים
- **לחיצות בלבד** - פחות שגיאות, פשוט יותר
- **קצר** - משפטים קצרים תמיד טובים יותר
- **אל תיתן מחיר** - אף פעם לא
- **העברה מיידית בחירום** - זה הערך הכי גדול בשביל האינסטלטור/חשמלאי הישראלי

## אם הבילדר לא תומך בשדה מדיה עם דילוג
החלף את שאלת התמונה בשאלת טקסט: `אם יש תמונה - שלח אותה. אם אין, כתוב "אין".`
זה פחות אלגנטי אבל עובד בכל גרסה.
