# איך לחבר את זרימת החירום ב-WATI

## סדר החיבורים הנכון
1. start -> חירום / דחוף מחובר ל-emergency_check
2. start -> פנייה רגילה מחובר ל-regular_name
3. emergency_check -> כל הכפתורים מחוברים ל-emergency_type (שמירת סוג התקלה)
4. emergency_type -> emergency_name
5. emergency_name -> emergency_address
6. emergency_address -> emergency_handoff (Human Handoff)
7. regular_name -> regular_address -> regular_issue -> regular_photo -> regular_summary
8. regular_summary -> העבר לנציג מחובר ל-handoff_regular_action (Human Handoff)

## המשתנים בהתראה לבעל העסק

ההתראה צריכה להראות ארבעה דברים: מי התקשר, איך חוזרים אליו, מאיפה, ומה הבעיה.
כל אחד מגיע ממקום אחר:

| מה מופיע | מאיפה מגיע | שם |
| :-- | :-- | :-- |
| מספר הטלפון של הפונה | מאפיין של וואטסאפ | `{{phone}}` |
| שם הפונה | נשמר בשאלת השם | `@emergency_name` |
| כתובת | נשמר בשאלת הכתובת | `@emergency_address` |
| סוג התקלה | נשמר מהכפתור | `@emergency_type` |

`{{phone}}` לא תמיד קיים - אם הפונה הסתיר את המספר שלו, ההתראה תגיע בלי טלפון.
לכן שם וכתובת הם לא קישוט: הם הדרך היחידה לחזור אליו.

**אל תקליד את המשתנים ביד** - בוחרים אותם מהבורר שבתוך הצומת. הקלדה ידנית
היא הסיבה הנפוצה ביותר להתראה שמגיעה עם `{{...}}` במקום ערך.

אם הודעת ההעברה יוצאת עם `@emergency_name` כמו שהוא, מוסיפים לפני ההעברה צומת
**Update Attribute** ששומר את המשתנה כמאפיין, ואז משתמשים ב-`{{emergency_name}}`.
