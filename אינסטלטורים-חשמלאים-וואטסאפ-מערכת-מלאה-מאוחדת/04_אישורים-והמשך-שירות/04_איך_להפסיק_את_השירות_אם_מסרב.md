# איך להפסיק את השירות אם הוא מסרב

עשה את זה מהר, בנימוס ובסדר.

## שלבים
| שלב | פעולה |
| :-- | :-- |
| **1.** | **תודה בנימוס** - *"בסדר גמור, תודה שבדקת את זה. אני מוריד את זה עכשיו."* |
| **2.** | **כבה את אוטומציית ההתראה** - זיהוי השיחה ושליחת הודעות ההתראה (אל תמחק את החשבון, פשוט כבה) |
| **3.** | **החזר מצב** - הסבר לו להחזיר את Call Forwarding למצב כבוי בהגדרות הטלפון. אם המודל הוא אפליקציה על המכשיר - הסר אותה |
| **4.** | **וודא** - תבקש ממנו להתקשר ולראות שהשיחה מגיעה ישירות אליו |
| **5.** | **תעד** - עדכן ב-CSV ל`הופסק` עם תאריך והסבר קצר ("לא המשיך לאחר ניסיון") |

**אם נמכר גם בוט:** הבוט וההתראה הם שני שירותים נפרדים. הסטטוס ב-CSV מתאר את
שירות ההתראה בלבד; מה קורה לבוט רושמים ב`הערות`.

- **ביטל רק את הבוט** - כבה רק את זרימת הבוט. זיהוי השיחה וההתראות ממשיכים,
  והסטטוס לא משתנה.
- **ביטל רק את ההתראה והשאיר את הבוט** - כבה את זיהוי השיחה ואת הודעות ההתראה,
  ועדכן ל`הופסק`. במודל B המספר נשאר ב-API כדי שהבוט ימשיך לעבוד, ולכן הוא לא
  חוזר לאפליקציית וואטסאפ - צריך לומר ללקוח את זה לפני הכיבוי.

## טיפים
- **אל תשכנע** - קבל את התשובה בכבוד
- **אל תציע הנחה** - אם אין לו תוצאות או פשוט לא רוצה, אין טעם
- **עשו את זה מייד** - אל תשאיר את האוטומציה פעילה
- **תשמור על קשר טוב** - לפעמים ימליץ לך בהמשך למרות שלא המשיך עכשיו
