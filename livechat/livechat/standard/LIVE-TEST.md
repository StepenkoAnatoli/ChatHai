# תבנית Meta ובדיקה חיה אחת

מה שכאן הוא רשימת בדיקה, לא הבטחה. פריטים שסומנו **[לאמת]** לא אומתו מול התיעוד של Meta או של הספק.

## 1. תבנית הוואטסאפ לשיחה שלא נענתה

- **שם:** `missed_call_he` (אותיות קטנות וקו תחתון)
- **שפה:** עברית (`he`) · **קטגוריה:** נבחר Utility. **[לאמת]** Meta מחליטה בסוף על הקטגוריה לפי הנוסח, ויכולה לסווג כ־Marketing (שיקול בעלות ובכללי הסכמה).
- **גוף (משתנה אחד, שם העסק):**

```
שלום, החמצנו את שיחתך אל {{1}}. אפשר לכתוב כאן במה מדובר ונחזור אליך.
```
- **דוגמה למשתנה (נדרשת בהגשה):** `אינסטלציה כהן`
- בלי קישורים, בלי מחיר, בלי הצעה, בלי כפתורים, כדי לא להידמות לשיווק.
- אפשר לנסח באנגלית כתבנית נוספת אם העברית נדחית.
- בשרת: `WHATSAPP_MISSED_TEMPLATE=missed_call_he`, `WHATSAPP_MISSED_TEMPLATE_LANG=he`.
- תבנית ההתראה לבעל העסק (`WHATSAPP_TEMPLATE`) נפרדת וכבר נדרשת מהשלב הקודם: גוף `{{1}}` אחד.

לפני הגשה **[לאמת]**: האם נדרש opt-in למי שרק התקשר, והאם תבנית שנשלחת למי שלא ביקש מותרת לפי מדיניות ההודעות של Meta ולפי חוק התקשורת (סעיף 30א, "ספאם"). אם התשובה היא שנדרש opt-in, הפתרון הוא הודעה מוקלטת/שלט שמבקש הסכמה בשיחה עצמה, ויש לשנות את הזרימה.

## 2. הכנה (פעם אחת)

1. אפליקציה ב־Meta for Developers עם מוצר WhatsApp, מספר בדיקה ו־**מספר הטלפון שלך** ברשימת הנמענים המותרים (מספר בדיקה שולח רק לרשימה הזו). **[לאמת]** המגבלות המדויקות של מספר הבדיקה.
2. אסימון גישה (עדיף של system user, לא אסימון זמני), `PHONE_NUMBER_ID`, ו־`App Secret`.
3. שרת עם כתובת HTTPS ציבורית (תעודה חתומה בידי רשות; Meta לא מקבלת self-signed). בפיתוח: מנהרה כמו Cloudflare Tunnel או ngrok.
4. משתני סביבה לשרת:

```bash
export MISSED_CALL_SECRET=<16+ תווים אקראיים>
export WHATSAPP_TOKEN=... WHATSAPP_PHONE_ID=...
export WHATSAPP_TEMPLATE=<תבנית ההתראה> WHATSAPP_MISSED_TEMPLATE=missed_call_he
export WHATSAPP_VERIFY_TOKEN=<מחרוזת שלך> WHATSAPP_APP_SECRET=<App Secret>
export CALL_PROVIDER=webhook CALL_WEBHOOK_URL=<n8n webhook> CALL_WEBHOOK_SECRET=<סוד>
export TRUST_PROXY=1   # רק מאחורי proxy שאתם שולטים בו
npm start
```
5. ב־App Dashboard ← WhatsApp ← Configuration: Callback URL `https://<הדומיין>/api/whatsapp/webhook`, Verify token כמו `WHATSAPP_VERIFY_TOKEN`, ואז הרשמה לשדה **messages**.
6. בדשבורד (התחברות לאתר): מספר וואטסאפ להתראות = המספר שלך, מספר חיוג חוזר = מספר אחר שלך או של חבר (כדי לשמוע שני טלפונים), "הפעלת השירות", ו"שווי עבודה ממוצעת".

## 3. תרחישים לבדיקה (סמנו ✓ או ✗ והוסיפו הערה)

| # | פעולה | תוצאה צפויה |
|---|---|---|
| 1 | שמירת ה־webhook ב־Meta | Meta מקבלת 200 ושומרת |
| 2 | `curl -X POST "https://<דומיין>/api/missed-call?site=<מפתח>" -H "x-webhook-secret: $MISSED_CALL_SECRET" -H "content-type: application/json" -d '{"caller":"05X-XXXXXXX"}'` (המספר שלך) | `{"ok":true,"sent":true}` והודעת התבנית מגיעה לוואטסאפ |
| 3 | אותה פקודה שוב | `sent:false, reason:recent`, לא נשלחת הודעה |
| 4 | להשיב "מה שעות הפעילות?" | תשובת ה־FAQ בוואטסאפ, אין התראה ואין חיוג |
| 5 | להשיב "יש נזילה!" | תשובת חירום עם 101/102, התראת "דחוף!" למספר ההתראות, בקשת חיוג ל־n8n/Twilio, הודעה "בעל העסק... יתקשר" |
| 6 | לענות לחיוג הגישור | המתקשר מחויג ומחובר |
| 7 | לא לענות לחיוג הבעלים | המתקשר לא מחויג, ההתראה בוואטסאפ הגיעה |
| 8 | לענות לחיוג הבעלים ולהשאיר לתא קולי | רושמים מה קורה (צפוי: המתקשר מחובר לתא קולי) |
| 9 | לענות מהדשבורד | הטקסט מגיע לוואטסאפ של המתקשר (בתוך 24 שעות מהודעתו) |
| 10 | לשלוח הודעה קולית | placeholder בדשבורד, התראה לבעלים |
| 11 | להשיב אחרי יותר מ־24 שעות | תשובת הבוט נכשלת (שגיאה בלוג). **[לאמת]** |
| 12 | `GET /api/report` או כרטיס "7 הימים האחרונים" | המספרים תואמים את הבדיקות |

## 4. אם הגישור דרך Twilio
`CALL_PROVIDER=twilio` ו־`TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM`. לבדוק **[לאמת]**: שמספר ה־From מאומת/שלכם, שהחיוג לישראל מותר בחשבון (הרשאות גיאוגרפיות), ושהקול העברי ב־`<Say language="he-IL">` נשמע תקין (אחרת להסיר את ה־Say או לעבור לאנגלית).

## 5. מה לרשום בסוף
תוצאת כל שורה בטבלה, נוסח התבנית כפי שאושר או נדחה (עם הסיבה), הקטגוריה ש־Meta קבעה והמחיר להודעה, וזמן האישור. את התוצאות יש להזין ל־`RESUME.md` ולהחליף את סעיפי "לא אומת" ב־`MISSED-CALL.md`.
