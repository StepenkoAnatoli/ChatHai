# צ׳אט חי לאתרים של לקוחות

צ׳אט חי בסגנון Tidio שאפשר להפעיל ללקוחות הפרילנס שלך. זו מימוש מקורי של אותו סוג מוצר, ולא העתקה של הקוד, העיצוב או המיתוג של Tidio. **כל הממשק בעברית ובכיווניות RTL**: הווידג'ט, לוח הבקרה, הודעות השגיאה, שאלות ברירת המחדל של הבוט והדוגמאות.

**מה זה עושה**

- בועת צ׳אט שהלקוח מדביק באתר שלו בעזרת תגית `<script>` אחת.
- בוט שעונה מתוך השאלות הנפוצות (FAQ) של כל לקוח, ואפשר לחבר אליו את Claude לשאלות שה־FAQ לא מכסה.
- כשהבוט לא בטוח, המבקר מקבל הודעת המתנה מנומסת והשיחה מסומנת **דורש התייחסות**.
- לוח בקרה בזמן אמת (עובד גם בטלפון) שבו הלקוח עונה כנציג אנושי. ברגע שנציג ענה, הבוט שותק עד שהשיחה מסומנת כמטופלת.
- הרבה לקוחות על שרת אחד: לכל אחד מפתח אתר, סיסמה, FAQ, צבע, ברכה ורשימת אתרים מותרים משלו.
- התראת מייל לבעל האתר כשמבקר כותב ואין נציג מחובר, ושורת פרטיות בווידג'ט (ניתנת לעריכה).
- התאמה מלאה לעברית: טקסט מימין לשמאל, והתאמת הבוט לצורות עברית (תחיליות כמו ה/ב/ל, ורבים).

## שתי גרסאות, אותה התנהגות

| | `zero/` | `standard/` |
|---|---|---|
| שרת | רק רכיבי Node מובנים (WebSocket כתוב ביד) | Node + חבילת `ws` |
| לוח בקרה | React נטען מ־CDN, בלי שלב בנייה | פרויקט React + Vite |
| התקנה | אין | `npm run setup` |
| מתאים ל־ | לנסות עכשיו, התקנות קטנות | מה שתמשיך לפתח ולתחזק |

שתיהן משתמשות באותו ווידג'ט, אותו API ואותו פורמט קובץ נתונים. אם אתה מתכנן להמשיך לפתח, התחל מ־`standard/`.

## מה נבדק

הכול הורץ בדפדפן Chromium אמיתי, עם מבקר ונציג שמדברים זה עם זה:

- 23 בדיקות קצה־לקצה של השרת, 9 בדיקות בוט ו־Claude API, ו־9 בדיקות פרוטוקול WebSocket (מסגרות שנבנו ביד: פיצול, ping/pong, גודל חריג, חבילות מפוצלות), בשתי הגרסאות.
- בדיקת דפדפן של 19 צעדים בשתי הגרסאות: התחברות, ווידג'ט, תשובת בוט, שיחה מסומנת, השתלטות נציג, תג הודעות שלא נקראו (גם אחרי רענון), HTML שמבקר כותב מוצג כטקסט רגיל, סיום טיפול, עריכת הגדרות, מבקר שני, ווידג'ט באתר אחר, כללי אתרים מותרים, פריסת מובייל, התנתקות והפעלה מחדש של השרת.
- בדיקות עברית: שאלות ברירת המחדל של הבוט נבדקות מול ניסוחים טבעיים בעברית, כולל שאלה לא קשורה שאסור שתקבל תשובה.
- שתי סבבי סקירה מצאו ותיקנו באגים (ראה `CHANGES.md`), ולכל תיקון יש בדיקה שנכשלת בלעדיו.

לא נבדק כאן, כי הסביבה לא הגיעה ל־registry של npm או ל־Claude API האמיתי:

- `npm install`, `vite build` ו־`vite dev` עבור `standard/` (קוד לוח הבקרה עצמו נארז ונבדק עם esbuild ו־React 19; ההתקנה אצלך תשתמש ב־React 18).
- לוח הבקרה של `zero/` מול unpkg האמיתי (נבדק עם חבילת React מקומית ותחליף ל־`htm`).
- מענה אוטומטי של Claude מול ה־API האמיתי (נבדק מול שרת מדומה שמוודא את פורמט הבקשה).

הרץ `npm test` בשתי התיקיות אצלך כדי לאשר.

## לפני שמעלים לקוחות אמיתיים

- שים אותו מאחורי HTTPS (Caddy או nginx; גם ה־WebSocket צריך לעבור דרך ה־proxy), הגדר `ADMIN_TOKEN` והגדר `TRUST_PROXY=1`. בלי `TRUST_PROXY`, כל המבקרים נראים כאילו הם מגיעים מה־proxy, והגבלת ניסיונות ההתחברות תהיה משותפת לכל הלקוחות שלך.
- גבה את `data.json`. הוא מכיל כל שיחה בטקסט גלוי. יידע את מבקרי הלקוחות שהשיחות נשמרות, והחלט כמה זמן שומרים אותן.
- מלא לכל לקוח **אתרים מותרים** (כתובות מלאות כמו `https://shop.example.com`; כתובת שגויה נדחית ולא מתעלמים ממנה). זה מונע מאתרים אחרים להשתמש במפתח האתר של הלקוח בדפדפן רגיל. זו לא חומת אבטחה: סקריפט שמזייף את הכותרת `Origin` עדיין יכול להתחבר, ולכן אסור להתייחס לצ׳אט כאל מידע פרטי.
- זהו תהליך יחיד עם קובץ JSON, מספיק לקומץ לקוחות קטנים. עבור למסד נתונים אמיתי לפני שגדלים מעבר לזה.
- נתונים קיימים: אתרים שנוצרו לפני המעבר לעברית שומרים את הברכה, ההודעה ושאלות ה־FAQ באנגלית. אפשר לשנות אותם בלשונית **הגדרות** בלוח הבקרה, או ליצור את האתר מחדש.

## הצעדים הבאים
